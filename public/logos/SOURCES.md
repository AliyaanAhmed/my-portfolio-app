# Product artwork

These unmodified SVG assets are from Microsoft's official Power Platform architecture icon collection:

- Reference and usage terms: https://learn.microsoft.com/en-us/power-platform/guidance/icons
- Download: https://download.microsoft.com/download/498606aa-6d27-4f13-aa5c-1401078c153b/Power-Platform-icons-scalable.zip

The product names accompany the logos in the portfolio's architecture diagrams and capability examples. Microsoft retains ownership of its artwork. Code Apps uses the Power Apps product logo, because it is a Power Apps capability; no separate Code Apps logo is invented.

Code Apps reference: https://learn.microsoft.com/en-us/power-apps/developer/code-apps/overview

## Azure, React, and TypeScript

- Azure artwork: https://learn.microsoft.com/en-us/azure/architecture/icons/ and https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip. The Document Intelligence symbol is supplied under the legacy `Form-Recognizers` filename in this official pack.
- React: the React mark is extracted from the official https://react.dev/ website SVG. Its vector geometry is retained; its standalone color uses the site's dark-theme cyan.
- TypeScript: the primary `ts-logo-128.svg` from https://www.typescriptlang.org/branding/typescript-design-assets.zip, via https://www.typescriptlang.org/branding/.
- The small JS label is a typographic language identifier, not a claim of an official JavaScript logo.
- Azure logo: https://github.com/devicons/devicon/blob/master/icons/azure/azure-original.svg. The AI toolkit entry uses the official Microsoft AI Builder logo from the Power Platform icon collection above.
